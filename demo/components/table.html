Editable rows with folding actions

In a .table--editable, cells hold .table__control inputs and selects that sit flush until hovered or focused (--number right-aligns figures). Mark rows with unsaved edits .table__row--changed and added rows .table__row--new. Give the actions cell data-overflow-actions and mark foldable buttons data-priority="low" (folds first) or "medium". Rows in the same .table__wrapper fold together, before the table would scroll sideways or a text input could no longer show its value; anything marked data-overflow-protect counts too. The script only sets data-overflow-level on the wrapper and the stylesheet hides what that level folds. The "⋯" menu is built when it opens, from each action's icon and aria-label or data-label, and floats in the top layer so the table can't clip it. This example is narrow, so its actions fold.
