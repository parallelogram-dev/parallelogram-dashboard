Auth

Centred page for signing in and the other screens shown before the dashboard shell.

Usage

.auth wraps the whole page and centres its .auth__container in the viewport, so the examples below show only the container. A card holds the header (auth__logo, auth__title, auth__description), the form and an auth__footer for the way back. auth__container--wide fits a longer form; auth__icon, with --success or --error, heads a screen that reports an outcome.
