Media Field

Contenir’s gallery field: asset tiles that reorder and remove, and a + tile that opens the file browser.

Examples

Gallery field

Each tile is an li.media.editable with data-handle for drag reordering and a .media__remove button that shows on hover or focus. The last tile, [data-filebrowser-add], holds a .media__btn that opens the file browser. Add .selected to highlight a tile. Class names match Contenir’s markup, so these styles apply to it unchanged.
