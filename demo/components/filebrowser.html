File Browser

Contenir’s browser for one set of site assets, with its dialog shell and upload panel: search, sort, grid and list views, selection, and drag-and-drop uploads with per-file progress.

Examples

Open the browser from a field

Press + to open the browser for Products › Images. Search, sort, switch between grid and list, and select several assets. Drop image files onto the browser (or use Upload) to see the upload flow: a drop overlay while dragging, cards with progress at the top of the grid, and a footer status whose Details slides out the upload panel. A file with “fail” in its name shows the error state.

Structure

dialog.overlay holds .overlay__wrap with two .overlay__inner panels: the browser (header, body, footer) and the upload panel, which slides over the browser’s right side when it has .show. The browser list is .filebrowser__list; add --image for the grid, otherwise rows show under .filebrowser__banner headings, and --single makes the choice single. Items are .filebrowser__item with a visually hidden .filebrowser__checkbox and a .filebrowser__label holding --select, --preview, --name, --mime, --type, --size, --time and --options.

States: .overlay__body--dragover shows the drop target (its text comes from --filebrowser-drop-label), .filebrowser__item--busy with .filebrowser__upload-progress is an upload in progress (width from --progress), --error a failed upload and --leaving an item being removed. .filebrowser__status in the footer summarises uploads; data-state="uploading" adds a spinner and "error" turns it red.
