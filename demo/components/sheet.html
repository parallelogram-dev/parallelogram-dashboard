Overlays

Sheet

Slide-out panels from screen edges.

Playground

Examples

A sheet is a <dialog class="sheet">. Buttons open it with commandfor="id" command="show-modal" and close it with command="close", so no JavaScript is needed in current browsers (main.js adds a fallback). showModal() traps focus, closes on Escape and makes the page behind inert. Add .sheet--left, .sheet--top or .sheet--bottom to change the edge.
